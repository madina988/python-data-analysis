Анализ данных о людях из CSV при помощи ручной обработки
Учебный Pet-проект: Программа читает CSV-файл и считает статистику

## Автор
Мадина

## Что делает
- Читает файл из 'data.csv'
- Считает средний возраст
- Считает сколько всего имён в файле
- Считает частоту имени Антон
- Сохраняет результат в 'result.csv'

## Пример результата
Средний возраст: 46.833333333333336
Сколько имен в файле: 6
Частота имени Антон: 0.3333333333333333

## Как запустить
1. Установить Python 3
2. В терминале выполнить: 'python main.py'

## Файлы
- 'data.csv' - исходные данные
- 'main.py' - код программы
- 'result.csv' - результат
